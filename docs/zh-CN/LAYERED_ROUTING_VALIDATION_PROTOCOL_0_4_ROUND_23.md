# 分层路由验证协议（0.4.0-alpha.2，Round 23）

Round 23 是第二轮独立资格研究。完整 12 目标清单位于 `../research/evidence/layered-routing-targets-round-23.json`，并且在利用 Round 22 结果修改产品或协议前冻结。候选、公开 baseline、每条件两次重复、顺序平衡的依序执行、四个语言家族、四种任务层次、真值定义与数值门槛都和 Round 22 相同。

Round 23 只有在以下条件全部满足时通过：引用补全与控制拒答都是 100%；可路由任务的核心与明确附属闭合都是 100%；宏观核心覆盖率至少 0.90；宏观 focus 至少 0.70；每个目标达到 0.50 覆盖与 0.40 focus；共同完成目标的覆盖与 focus 在 -0.05 内非劣；重复路线确定一致；并且没有过度自信、错误强制停止、tracked-file 污染、指标分歧或超过 6000 估算 Token 的 context。

第一次观察结果不可改写。如果 Round 22 或 Round 23 任一失败，就不发布 `0.4.0`，npm `latest` 继续保持 `0.3.0`。只有同一份未修改的 alpha.2 产品连续通过两轮全新研究，才获得 stable 发布资格。

这仍是静态路由证据。任何 Token、时间或工具调用声明，都必须另外完成 24 对真实 Agent A/B。
