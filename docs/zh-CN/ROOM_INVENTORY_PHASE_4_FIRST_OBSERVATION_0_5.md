## 诊断出的失败类别

首次观察支持一个通用失败类别：**复合任务 facet 闭合缺少所有权约束**。

- 即使明确的 parser、compatibility 或 generated 义务仍未满足，规划器也可能在实现与验证后停止。
- 找到主路线后，词法相似度可能压过同语言、同所有权证据。
- 已索引的生成 provenance 没有变成明确任务义务。
- 明确 facet 未闭合时，置信度仍可能过高。

## 允许的修复方向

该失败类别只允许一次通用机制修复：

1. 从明确子句推导有界 facet 义务。
2. 优先选择与锚点同语言、同所有权且有关系连接的证据。
3. 任务明确要求生成输出时，使用已索引的 generated provenance。
4. 惩罚无关 scope 扩张，并在任何明确 facet 未闭合时限制置信度。

修复代码禁止包含夹具路径、目标 ID、symbol 名称、仓库名或语言专用预期文件名。
