# 本地盲选配对路由验证协议（0.4 Alpha，Round 11）

## 状态与证据边界

本协议和验证器在 Round 11 选出 8 个“整项任务语义一致”的真实历史改动后、第一次对任何入选任务调用 Vertex Palace 前，以 SHA-256 在本机冻结。候选产品、比较基线、仓库池、候选队列、逐 hunk 语义审核、任务顺序与最终目标清单都已先行冻结。

比赛结果公布前禁止提交和推送，因此这只是可检查、防篡改的本地研究，不是公开预注册。它只评估静态证据路由，不能宣称 Agent 正确率、端到端回报 Token 节省、Agent 工具调用减少或 Agent 执行时间下降。

## 研究问题

面对 8 个从未用于调参的新仓库与语义一致的真实历史任务，冻结候选能否完整找回实现、聚焦验证与有界辅助证据，同时维持路线聚焦、置信度校准、模式安全，并把实际交付上下文控制在 6,000 个估算 Token 内？

固定优先级如下：

1. 任务类型正确；
2. 实现与聚焦验证证据完整；
3. 改动文件覆盖率与路线聚焦度；
4. 置信度校准与安全模式选择；
5. 实际交付 payload；
6. 静态命令时间。

较小 payload 或较短时间不能补救正确性与证据门失败。

## 冻结输入

验证冻结文件以 SHA-256 绑定：

- Round 11 目标清单与 8 个 coherence packet 哈希；
- Round 11 候选冻结、源码树、CLI 与生成后的 MCP bundle；
- 修复前比较基线 commit 与离线重建的 CLI 哈希；
- 本协议的英文与简体中文版；
- 验证器、冻结生成器、完整性测试、telemetry helper 与冻结任务分类器。

任一哈希不一致，都必须在读取首个目标的 Palace 结果前停止。首份 create-only 结果保存前，不得修改产品代码。

## 配对执行

目标依照冻结清单顺序逐一执行。偶数索引先 baseline 后 candidate，奇数索引先 candidate 后 baseline，形成 4 个 AB 与 4 个 BA；两个条件绝不并行。

每个目标、每个条件都执行：

1. 取得冻结的完整 shallow history，并验证 Git oracle；
2. 在冻结改动的 parent commit 建立隔离仓库；
3. 以 `init`、`index`、`status` 建立全新的 `.palace`；
4. 正式重复两次 `evaluate`，随后运行 `context --auto`；
5. 独立重算改动文件、实现、聚焦测试与辅助证据覆盖率；
6. 记录置信度校准、模式、证据状态、停止执行、边界重叠、payload 与静态时间；
7. 检查路线确定性、索引新鲜度、指标一致性与目标仓库 tracked worktree 干净度。

静态门不会运行目标测试，也不会让编码 Agent 执行任务。

## 固定限制

- 8 个目标，每种语言家族恰好 2 个；
- baseline 与 candidate 两个条件；
- 每个目标、每个条件重复 2 次；
- 每个条件 16 次正式观察，共 32 次；
- 上下文上限 6,000 估算 Token；
- 路线最多 10 个文件，drawer 最多 4 个；
- 完整 shallow history 深度 400；
- 目标 materialization 最多尝试 3 次；
- 显式 index 只尝试 1 次，上限 900 秒；
- `evaluate` 与 `context` 不重试；
- 校准容差 0.15；
- 全程顺序执行，不并行。

即使采用平衡条件顺序，操作系统与文件系统缓存仍不完美，因此静态耗时仅作描述。

## 候选绝对门

候选必须同时满足：

1. 8/8 目标与 16/16 candidate 重复全部完成；
2. 8/8 任务类型正确；
3. 8/8 实现与路径推导的聚焦测试证据完整；
4. 所有预先登记的辅助证据完整；
5. 两次重复的路线成员与顺序完全确定；
6. 目标宏平均改动文件覆盖率至少 0.90；
7. 目标宏平均路线聚焦度至少 0.70；
8. 每个目标覆盖率至少 0.50，聚焦度至少 0.40；
9. 过度自信、危险窄模式、危险强制停止都为 0；
10. 指标分歧与 evaluate/context 路线分歧都为 0；
11. 每个 payload 不超过 6,000 估算 Token；
12. selected 与 excluded 边界不重叠；
13. 显式索引保持新鲜，且 Palace 不修改目标仓库的 tracked 文件。

baseline 接受相同的描述性门。baseline 失败不会使研究无效。

## 前进规则

只有以下条件全部成立，才可进入另行冻结的端到端 Agent A/B：

- 研究有效并完整结束；
- candidate 通过全部绝对门；
- candidate 宏平均覆盖率不比 baseline 低超过 0.05；
- candidate 宏平均聚焦度不比 baseline 低超过 0.05；
- 危险窄模式与危险强制停止没有增加。

如果未通过，首份结果仍是有效的负面或混合产品结果。观察结果后不得删除目标，首份结果保存前不得调产品。之后的任何修复都会使 Round 11 全部目标转为 disclosed regression，不再是 held-out 证据。
