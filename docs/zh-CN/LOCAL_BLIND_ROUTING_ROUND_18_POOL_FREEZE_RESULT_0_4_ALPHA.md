# 本地盲测路由第 18 轮仓库池冻结结果（0.4 Alpha）

## 结果

第 18 轮在 URL+HEAD-only 仓库池构建阶段停止。计划中的第 4 个仓库
`https://github.com/serde-rs/ryu.git` 返回 `Repository not found`。create-only 失败记录器
保存了前三个成功 HEAD 和精确失败诊断，没有写入 canonical 仓库池。

这是协议输入结果，不是 Vertex Palace 产品表现结果。

## 已保留边界

- 查询后没有修改冻结计划或顺序。
- 没有偷偷插入替代仓库。
- 三个成功 HEAD 与失败的第四个身份都会被后续轮次递归排除。
- 没有检查历史、subject、diff、任务、语义审核或 oracle。
- 对候选任务的 Palace 调用保持为 0。
- 目标选择、静态验证与 v5 Agent A/B 均未获授权。

## 协议学习

连续两个旧仓库 URL 失效，说明“一个 URL 不可达就废掉整轮”过于脆弱。可达性是基础设施元数据，
不是产品结果。下一协议会先冻结更大的有序 URL roster，只查询 HEAD 并记录全部结果；只机械跳过
明确不存在的 URL，再按语言家族选择固定数量的最早可达仓库。瞬时网络错误重试耗尽时仍会中止，
不会借网络波动静默改变样本。
