## 通用机制修复

修复增加内部证据面规划器，但不改变公开 `EvidenceRole` 词汇：

- 明确任务子句转换为有界 identifier、concern、constraint、verification 或 generated 义务。
- Identifier 义务必须精确命中对象身份，不能只因共享一个通用词就算闭合。
- 候选证据必须在两个来源级 hop 内存在关系连接。
- 非生成证据必须保持与锚点相同语言和所有权范围，除非有精确 identifier 证明。
- 明确的生成工作可以沿已索引 provenance 扩张两跳。
- 候选增益继续使用预注册的任务相关度、关系强度、facet 增益、连接度惩罚与冗余模型。
- 任一明确 facet 未闭合时，路线置信度上限为 `0.40`。
- 没有 Room Inventory 元数据时规划器不启用，因此默认行为保持不变。

产品代码没有夹具路径、目标 ID、预期 symbol、仓库名或 issue 编号。
