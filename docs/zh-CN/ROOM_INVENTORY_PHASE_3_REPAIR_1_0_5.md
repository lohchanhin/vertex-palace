## 通用机制修复

产品代码没有加入夹具名称、对象身份、预期路径或仓库专用规则：

- 可选、只存在于解析阶段的 `objectReferences` 为 Room Inventory 保留完整结构化标识符，不建立第二套持久图。
- 支持 Go 标准 `*_test.go` / `TestXxx` 与 Rust `#[test]` 测试对象识别。
- Owner 到直接成员使用 `contains` 表达，不再重复推断成 `calls`。
- 只有存在 Room Inventory 元数据时，更具体的来源 symbol 才会压制严格 token 子集的宽泛 Owner 测试匹配。
- 默认索引不启用该特异性过滤，因此保持 0.4 图不变。
