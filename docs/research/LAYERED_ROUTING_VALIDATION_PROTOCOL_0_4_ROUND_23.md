# Layered Routing Validation Protocol (0.4.0-alpha.2, Round 23)

Round 23 is a second independent qualification round. Its complete 12-target manifest is `evidence/layered-routing-targets-round-23.json`, frozen before Round 22 results are used to alter any product or protocol input. It uses the same candidate, public baseline, two repetitions, balanced sequential order, four language families, four task strata, truth-layer definitions, and numerical gates as Round 22.

Round 23 passes only when reference grounding and control abstention are both 100%; routable core and declared auxiliary closure are 100%; macro core coverage is at least 0.90; macro focus is at least 0.70; every target satisfies 0.50 coverage and 0.40 focus; common-target coverage and focus are non-inferior within -0.05; repeated routes are deterministic; and there is no overconfidence, wrong forced stop, tracked-file pollution, metric disagreement, or context above 6,000 estimated tokens.

Its first observed result is immutable. If Round 22 or Round 23 fails, `0.4.0` is not published and npm `latest` remains `0.3.0`. Only two consecutive passing fresh rounds qualify the unchanged alpha.2 product for stable release.

This remains static-routing evidence. The separate 24-pair Agent A/B is required for any Token, wall-time, or tool-call claim.
